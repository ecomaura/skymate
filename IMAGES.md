# SkyMate image assets

Custom, lightweight SVG illustrations are included in `assets/images/` and connected to the image placeholders across the site.

| File | Placement |
|---|---|
| hero-team.svg | Home hero: small business owner using digital tools |
| setup-gbp.svg | Google Business Profile setup card |
| setup-maps.svg | Google Maps and local discovery card |
| setup-instagram.svg | Instagram business profile card |
| setup-facebook.svg | Facebook business page card |
| setup-whatsapp.svg | WhatsApp Business chat and catalogue card |
| band-dashboard.svg | Home growth dashboard section |
| services-hero.svg | Services page hero |
| services-audit.svg | Services audit section |
| about-team.svg | About page team illustration |
| about-office.svg | About page workspace illustration |
| contact-map.svg | Contact page location/map illustration |

The illustrations use the site's blue, green and orange palette and load through the existing `data-img` placeholder mechanism.
